# Requirements 🔧

In order to follow this guide they will need to use a console and install the following software:

## 1) Shell.

### Linux/BSD/Mac:

I suggest one of the following: 
* [**Bash.**](https://www.gnu.org/software/bash/)
* [**Fish.**](https://fishshell.com/)
* [**Zsh.**](https://www.zsh.org/)

### Windows:

* **Powershell:**Installed by default on Windows.
* [**Mingw.**](https://www.mingw-w64.org/)


## 2) GIT.

### Linux/BSD/Mac:
Use your favorite package manager (APT for Debian):
```shell
rafa@debian:~/home/proyect$ sudo apt update && apt install git 
```

Verify that it was successfully installed with this command:
```shell
rafa@debian:~/home/proyect$ git version 
git version 2.47.3
```

### Windows:
* Download the official installer from [**GIT for Windows.**](https://git-scm.com/downloads)
* Or you can use Chocolatey package manager: https://community.chocolatey.org/packages/git

## 3) Text editor or IDE: 

I suggest one of the following: 
* [**VI/VIM.**](https://www.vim.org/download.php)
* [**VS Code.**](https://vscodium.com/#install)
* [**Geany.**](https://www.geany.org/download/releases/)
* [**Zed editor.**](https://zed.dev/)
